## 후기

- 최선희: DRF 없이 기존 Django 템플릿 환경에 Axios와 JsonResponse를 결합해 비동기(AJAX) 통신을 구현해 보았습니다.

기존 Django 방식처럼 매번 페이지 전체를 새로고침하는 대신, event.preventDefault()로 기본 동작을 막고 Axios로 필요한 데이터만 JSON 형태로 주고받는 흐름을 확실히 익혔습니다.

댓글을 비동기로 새로 추가했을 때, 새로고침 없이 바로 삭제까지 되도록 구현하면서 이벤트 위임의 중요성을 알게 되었습니다.

ERD를 통해 Comment 모델이 Thread와 User를 외래키(FK)로 참조하는 구조를 확인하고, form.save(commit=False)로 외래키를 채워 넣은 뒤 저장하는 이유를 더 명확히 이해했습니다.

기능별로 브랜치를 나누고 HTML 파일이 겹치지 않게 역할을 분담한 덕분에, 병합 과정에서 충돌을 최소화하며 효율적으로 프로젝트를 마무리할 수 있었습니다. 

- 김석환: F1001 유저 팔로우 기능, F1004 도서 장르 필터링 기능을 구현 하였습니다.

F1001에서는 다른 사용자를 팔로우 하거나 언팔로우 하면 새로고침 없이 팔로워 수와 버튼 문구가 바뀌도록 구현했습니다.
F1004에서는 처음에 전체 도서를 보여주고, 장르를 선택하면 해당 장르의 도서만 표시하도록 구현했습니다.

followings와 followers가 다대다의 관계를 가지고 누구를 기준으로 조회되는지 배웠습니다.
axios로 요청을 보내고 Django의 JsonResponse로 받은 데이터를 이용해 화면 일부를 갱신하는 흐름을 익혔습니다.

서버 응답과 브라우저 동작을 따로 확인하니 오류가 어느 쪽에서 발생하는지 찾기 수월했습니다.
git을 이용함에 있어 팀원과 초기 규칙, 설정, 소통이 중요하다는 것을 느꼈습니다.
