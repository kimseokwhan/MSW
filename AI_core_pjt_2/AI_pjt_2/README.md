# 🎓 UniGuide — 국내 대학·학과 탐색 RAG 서비스

AI 코어 프로젝트 2회차 · RAG 기반 도메인 지식 서비스

## 1. 프로젝트 개요

국내 4년제 대학 **198곳**(학과 10,615개)의 **학과 공시 정보**와 **한국어 위키백과 문서**를 근거로, 대학·학과에 관한 자연어 질문에 답하고 답변의 근거를 함께 보여준다.

- "서울 소재지 대학 알려줘", "간호학과와 약학과가 모두 있는 대학은?" → 조건에 맞는 대학 목록
- "연세대는 언제 설립됐어?", "경상국립대 경영정보학과 입학정원은?" → 특정 대학 질문 (필요한 위키 문서를 자동 수집)
- 두 대학을 골라 관심 분야 기준으로 비교

모든 답변은 수집한 근거 안의 내용만 사용하고 `[근거 n]`과 원문 출처를 표시한다. 근거가 없으면 "제공된 문서에서 확인되지 않습니다"로 답한다.

## 3. 실행 방법

```bash
# 1) 가상환경과 라이브러리
python -m venv venv
source venv/Scripts/activate         # PowerShell: venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2) 키 설정: .env.example을 .env로 복사하고 값 입력
#    GMS_KEY(SSAFY GMS), DATA_API_KEY(공공데이터포털), WIKI_CONTACT(본인 이메일)

# 3) 데이터 준비와 색인 (최초 1회)
python data.py       # 공공데이터 → data/universities.json (대학 198곳, 약 3분)
python index.py      # 대학 메타데이터 색인 (다시 실행해도 198건 유지)

# 4) 앱 실행
streamlit run app.py
```

## 4. 기능

### 4.1 필수 기능 (F2001 ~ F2012)

| 번호 | 기능 | 구현 |
|---|---|---|
| F2001 | 항목 메타데이터 적재 | 공공데이터 학과정보 → 대학 198곳, 대학 1곳 = 학교명·구분·소재지·학과 수·정원·계열·학과(정원)·관련 직업 텍스트 |
| F2002 | 메타데이터 색인 (RAG 1) | `univ_meta` 컬렉션, 대학당 1청크, 청크 ID = 대학명 (재색인 시 덮어쓰기) |
| F2003 | 검색어 추출 (프롬프트 1) | 진학 상담 전문가 역할, JSON 배열(최대 3개) |
| F2004 | 외부 문서 수집 (프롬프트 2) | 위키 후보 제목·요약으로 선별(최대 2개) 후 본문 수집, 대학 자체 문서는 항상 포함, 이미 수집한 검색어·질문은 재수집 안 함 |
| F2005 | 외부 문서 색인 (RAG 2) | `univ_docs` 컬렉션, 1,000자/200자 청크(설정), 청크 ID = `대학ID:문서ID:순번` |
| F2006 | 근거 검색 및 병합 | 대학 메타 청크(항상) + 그 대학 범위 위키 청크 Top-k(기본 5, 슬라이더) → 병합·중복 제거 |
| F2007 | 근거 기반 답변 생성 (프롬프트 3) | LangGraph `retrieve → generate`, 출처 유형(대학 학과 공시/위키백과) 구분, 근거 없으면 "확인되지 않습니다" |
| F2008 | 근거 표시 | 본문에 인용된 `[근거 n]`만 제목·출처 유형·원문 링크로 표시, 인용 없으면 안내 |
| F2009 | 항목 선택 및 질의응답 | 사이드바 '질문 대상'(전체 대학/특정 대학, 검색창), 대상별 대화 분리 |
| F2010 | 도메인 특화 기능 | **대학 비교**: 두 대학 비교표 + 차이점, 모든 사실에 근거 |
| F2011 | 조건 기반 항목 탐색 | 지역·학과명·학교명 조건으로 198개 대학을 직접 거름 → 대학 버튼으로 그 대학 질문 이어가기 |
| F2012 | 진행 상태 및 안내 | 수집·생성 진행 상태, 색인 없음·키 누락 안내, 면책 문구, 구분할 수 없는 조건(국립/사립 등) 경고 |

추가 기능: 대학 검색창, 질문 가능 조건 안내, 대화 지우기, 맨 위/맨 아래 이동 버튼.

### 4.2 심화 기능 (F2013 ~ F2016)

선택하지 않았다. 필수 기능의 정확도(조건 탐색 결과의 누락·오답 0건)를 높이는 데 집중했다.

### 4.3 질문 처리 방식

| 질문 예 | 근거로 쓰는 것 |
|---|---|
| "연세대는 언제 설립됐어?" (대학명) | 그 대학 공시 정보 + 그 대학 위키 문서 청크 (처음이면 위키 문서를 먼저 수집) |
| "간호학과와 약학과가 모두 있는 대학은?" / "여자대학교 알려줘" (학과·학교명 조건) | 198개 대학을 조건으로 직접 거른 결과 |
| "서울 소재지 대학 알려줘" (지역) | 그 지역 대학 전체 |
| 그 밖의 질문 | 질문과 의미가 가까운 대학 15곳 |

**구분할 수 없는 조건**: 국립/사립 설립 유형(공시 데이터에 항목 없음), 순위·합격선·경쟁률·취업률·등록금, KAIST 등 공시 대상이 아닌 학교, 전문대학·대학원. 화면에 안내하고, 질문에 이런 말이 있으면 경고를 붙인다.

## 5. 데이터 준비 및 색인 절차

1. **항목 메타데이터** (`python data.py`): 공공데이터 API에서 4년제 학교 이름을 모은 뒤 학교별로 다시 조회해 원본 48,086행을 받는다(`data/raw/` 캐시). 학사과정만 남기고 학과를 대학 단위로 묶어 `data/universities.json`(198곳)을 만든다.
2. **메타데이터 색인** (`python index.py`): 대학 1곳을 하나의 텍스트로 만들어 임베딩하고 `univ_meta`에 upsert한다.
3. **외부 문서 수집·색인** (앱 사용 중 자동): 질문에 대학명이 있으면 프롬프트 1 → 위키 검색 → 프롬프트 2 → 본문 수집(`data/docs/`) → 청킹 → `univ_docs` 색인. 수집 기록은 `data/collect_log.json`.
4. **청크 설정 변경**: `.env`의 `CHUNK_SIZE`·`CHUNK_OVERLAP`을 바꾸고 `python index.py --docs`로 받아 둔 문서를 다시 청킹한다.

검증용 명령:

```bash
python index.py --show 서울대학교            # 대학 1건의 색인 텍스트
python rag.py                                 # LangGraph 구조 출력
CHUNK_SIZE=500 python index.py --docs         # 청크 설정 바꿔 재색인 (Git Bash)
python index.py --docs                        # 원래 설정으로 되돌리기
```

## 7. 기술 스택

Python 3.11 · Streamlit 1.62 · LangChain 1.3 · LangGraph 1.2 · ChromaDB 1.5 · SSAFY GMS(`gpt-4.1-mini`, `gpt-5.4-mini`, `text-embedding-3-small`)

| 파일 | 역할 |
|---|---|
| `config.py` | 키(.env), 모델, 경로, 청크·Top-k 설정 |
| `data.py` | 데이터 준비: 공공데이터 수집, 대학 텍스트, 위키백과 API, 질문 조건 분석, 도메인 문구 |
| `index.py` | Vector DB(Chroma): 메타데이터 색인(RAG 1), 위키 문서 청킹·색인(RAG 2) |
| `rag.py` | 프롬프트, 위키 문서 수집, LangGraph `retrieve → generate`, 대학 비교 |
| `app.py` | Streamlit 화면 |
