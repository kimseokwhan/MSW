# 요구사항 정의서 — UniGuide (국내 대학·학과 탐색 RAG 서비스)

AI 코어 프로젝트 2회차 · RAG 기반 도메인 지식 서비스

## 1. 프로젝트 개요

국내 4년제 대학 198곳의 **학과 공시 정보**(공공데이터)와 **한국어 위키백과 문서**를 근거로, 사용자가 자연어로 대학·학과를 찾고 질문할 수 있는 서비스다. 모든 답변에는 근거 번호 `[근거 n]`과 원문 출처를 함께 보여준다.

- 서비스명: UniGuide
- 사용자: 진학할 대학·학과를 탐색하는 고등학생, 학부모, 진로 상담 교사
- 대표 사용 장면
  - "서울 소재지 대학 알려줘", "간호학과와 약학과가 모두 있는 대학은?" — 조건으로 대학 찾기
  - "연세대는 언제 설립됐어?", "경상국립대 경영정보학과 입학정원은?" — 특정 대학 질문
  - 두 대학을 골라 관심 분야 기준으로 비교

## 2. 도메인과 선택 조건 충족 근거

| 조건 | 충족 근거 |
|---|---|
| **항목 메타데이터 (약 100건 이상)** | 한국대학교육협의회 대학별 학과정보 API(2025년 공시) 원본 48,086행 → 4년제(대학교 186·교육대학 10·산업대학 2) 학사과정 **대학 198곳 / 학과 10,615개**. 대학 1곳이 항목 1건이다. |
| **외부 문서 출처** | 한국어 위키백과 API. 대학마다 대학 자체 문서와 캠퍼스·단과대학 문서가 있어 설립 연혁, 캠퍼스 위치 등 공시 데이터에 없는 정보를 보완한다. |
| **출처와 이용 조건 기록** | 아래 2.1 표. 근거마다 원문 URL을 화면에 표시한다. |
| **근거가 필요한 질문** | 아래 2.2. 입학정원·학과 구성은 해마다 바뀌고, 학교마다 학과명이 달라 일반 지식으로 답하면 틀리기 쉽다. |
| **위험 도메인 여부** | 건강·금융은 아니지만 진학 결정은 잘못 안내되면 피해가 크다. 면책 문구를 사이드바에 항상 표시한다: *"입학정원·전형은 해마다 바뀌므로 지원 전에는 반드시 각 대학 입학처의 최신 모집요강을 확인하세요. 진학 상담을 대신하지 않습니다."* |

### 2.2 근거 없이 답하면 틀리기 쉬운 질문 예시

| 질문 | 근거 없이 답할 때의 위험 | 근거 |
|---|---|---|
| 경상국립대 경영정보학과 입학정원은? | 정원은 해마다 바뀌어 일반 지식으로는 틀린 숫자를 말하기 쉬움 | 학과 공시 (38명, 2025년) |
| 간호학과와 약학과가 모두 있는 대학은? | 일부만 기억해 누락하거나, 바이오의약학과를 약학과로 착각 | 학과 공시 (29곳) |
| 연세대는 언제 설립됐어? | 1885년(광혜원)·1915년·1957년(통합) 등 기준이 여러 개라 혼동 | 위키백과 |
| 연세대 캠퍼스는 어디에 있어? | 국제캠퍼스(송도)를 빠뜨리기 쉬움 | 위키백과 |
| 서울대 2026학년도 수시 합격선은? | 근거가 없는데도 추측해 답할 위험 → 서비스는 "확인되지 않습니다"로 답해야 함 | (없음) |

## 3. 기능적 요구사항

우선순위: 필수 / 심화. 구현 결과: ✅ 구현, ➖ 미선택.

| 번호 | 분류 | 요구사항명 | 요구사항 상세 (UniGuide 적용) | 우선순위 | 구현 |
|---|---|---|---|---|---|
| F2001 | 데이터 | 항목 메타데이터 적재 | 공공데이터 학과정보를 받아 대학 198곳으로 묶고, 대학 1곳을 학교명·학교 구분·소재지·학과 수·입학정원·계열 구성·학과(정원)·관련 직업이 담긴 하나의 텍스트로 구성한다. | 필수 | ✅ |
| F2002 | 색인 | 메타데이터 색인 (RAG 1) | 대학 텍스트를 임베딩해 `univ_meta` 컬렉션에 대학당 1청크로 색인한다. 청크 ID는 대학명이라 다시 색인해도 중복 저장되지 않는다. | 필수 | ✅ |
| F2003 | 프롬프트 | 검색어 추출 (프롬프트 1) | 진학 상담 전문가 역할 프롬프트로 대학과 질문에서 위키백과 검색어를 JSON 배열(최대 3개)로 추출한다. 대학 자체 문서는 항상 검색 대상에 넣는다. | 필수 | ✅ |
| F2004 | 수집 | 외부 문서 수집 (프롬프트 2) | 검색어마다 위키 후보의 제목·요약만 보여주고 선별 프롬프트로 색인할 문서(최대 2개)를 고른 뒤 본문과 원문 URL을 수집한다. 대학 자체 문서는 선별·길이 규칙보다 우선해 항상 색인한다. 이미 수집한 검색어·질문은 다시 수집하지 않는다. | 필수 | ✅ |
| F2005 | 색인 | 외부 문서 색인 (RAG 2) | 문서를 1,000자 청크 / 200자 중복으로 나눠 `univ_docs` 컬렉션에 색인한다. 청크 ID는 `대학ID:문서ID:순번`. 청크 값은 설정(.env)으로 바꾼다. | 필수 | ✅ |
| F2006 | 검색 | 근거 검색 및 병합 | 질문한 대학의 메타데이터 청크는 항상 넣고, 위키 청크는 그 대학으로 범위를 좁혀 Top-k(기본 5) 검색한 뒤 병합·중복 제거한다. Top-k는 설정과 화면 슬라이더로 바꾼다. | 필수 | ✅ |
| F2007 | 생성 | 근거 기반 답변 생성 (프롬프트 3) | LangGraph `retrieve → generate` 두 노드. 근거마다 출처 유형(대학 학과 공시 / 위키백과)을 붙이고, 근거에 없으면 "제공된 문서에서 확인되지 않습니다"로 답한다. | 필수 | ✅ |
| F2008 | 생성 | 근거 표시 | 답변 본문의 `[근거 n]`을 찾아 실제로 인용된 근거만 제목·출처 유형·원문 링크와 함께 표시한다. 인용이 없으면 그 사실을 안내한다. | 필수 | ✅ |
| F2009 | UI | 항목 선택 및 질의응답 | 사이드바의 '질문 대상'에서 전체 대학 또는 특정 대학을 고르고(검색창 제공) 채팅으로 질문한다. 대화 기록은 질문 대상별로 따로 유지한다. | 필수 | ✅ |
| F2010 | 서비스 | 도메인 특화 기능 | **대학 비교**: 두 대학과 관심 분야를 고르면 공시 정보와 위키 문서만으로 비교표·차이점을 만들고 근거를 표시한다. | 필수 | ✅ |
| F2011 | 서비스 | 조건 기반 항목 탐색 | 자연어 조건(지역·학과명·학교명)으로 198개 대학을 거르고 조건에 맞는 대학만 목록으로 제시한다. 답변 아래 대학 버튼을 누르면 그 대학 질문으로 이어진다. | 필수 | ✅ |
| F2012 | UI | 진행 상태 및 안내 | 문서 수집·답변 생성 중 진행 상태를 표시하고, 색인 없음·키 누락 안내, 면책 문구, 데이터로 구분할 수 없는 조건(국립/사립 등) 경고를 표시한다. | 필수 | ✅ |
| F2013 | UI | 프론트엔드 직접 구현 | HTML/CSS/JS 화면 | 심화 | ➖ |
| F2014 | 검색 | MMR 검색 적용 | 유사도 검색 대신 MMR | 심화 | ➖ |

## 4. 비기능적 요구사항

| 번호 | 분류 | 요구사항명 | 요구사항 상세 (UniGuide 적용) |
|---|---|---|---|
| NF2001 | 성능 | 응답 시간 | 이미 수집한 대학·목록형 질문은 수 초 안에 답한다. 처음 묻는 대학은 위키 문서 수집 때문에 수십 초까지 걸릴 수 있으므로 진행 상태를 보여준다. |
| NF2002 | 성능 | 수집 캐시 | (대학, 검색어)와 (대학, 질문) 단위로 수집 기록을 `data/collect_log.json`에 남기고, 문서 원문은 `data/docs/`에 한 번만 저장한다. 공공데이터 원본도 `data/raw/`에 캐시한다. |
| NF2003 | 보안 | API 키 관리 | GMS·공공데이터 키와 위키 연락처는 `.env`에만 두고 `.gitignore`로 제외한다. |
| NF2004 | 보안 | 내부 정보 비노출 | 오류는 사용자용 문구로만 표시하고 상세는 터미널 로그에만 남긴다. `.streamlit/config.toml`에서 `showErrorDetails = "none"`. 프롬프트 전문은 화면에 보이지 않는다. |
| NF2005 | 확장성 | 모듈 분리 | 데이터 준비(`data.py`) · 색인(`index.py`) · 검색·생성(`rag.py`) · UI(`app.py`) · 설정(`config.py`)으로 분리하고, 도메인에 묶인 부분(대학 텍스트, 지역명, 조건 안내, 면책 문구)은 `data.py`에 모은다. |
| NF2006 | 품질 | 외부 API 예절 | 호출 간 최소 간격(위키 0.5초, 공공데이터 0.2초), 429·5xx·네트워크 오류는 최대 3회 지수 백오프 재시도. 위키백과 User-Agent에 연락처를 넣는다. |
| NF2007 | 법·윤리 | 출처와 이용 조건 | 2.1 표에 출처와 이용 조건을 기록하고, 위키 근거마다 원문 URL을 표시한다(CC BY-SA 출처 표시). |

## 5. 제약 사항과 한계

| 항목 | 내용 |
|---|---|
| 국립/공립/사립 구분 불가 | 학과정보 API에 설립 유형 필드가 없다. 이름에 '국립'이 들어간 학교만 찾을 수 있어 서울대·부산대 등은 빠진다. 질문에 '국립/사립'이 있으면 경고를 붙인다. (개선안: 대학알리미 학교 기본정보의 설립구분 추가) |
| 공시 대상 외 학교 | KAIST·GIST·UNIST·DGIST·한국예술종합학교·경찰대·사관학교는 데이터에 없다. |
| 범위 | 4년제 학사과정만 다룬다. 전문대학·대학원은 제외한다. |
| 수치 기준 | 입학정원은 2025년 공시 기준이며 실제 모집 인원과 다를 수 있다. |
